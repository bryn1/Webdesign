## Overview

`projects/salong` is one content wearing many full designs, not one design system. `spec.md` is the content canon: "Samma sektioner, samma svenska copy, samma kontaktdata, samma ärlighetsregler" — "endast design, typografi, palett och scroll-koreografi skiljer temana åt" (spec.md). Under `prototypes/` stand 28 numbered theme folders: 00-poc-live-site (the live-PoC snapshot, its own `images/`), 01–20 the gallery themes, 21–26 impeccable lab fixtures ("an impeccable-skill test build", each named in its `SOURCE.md`), and 27-salongens-rytm, the owner-ratified-name theme. Every theme is a whole site — "tema ska kännas som en riktig sajt, ej en variant av en grund" (spec.md) — so one token table written here would be the fiction this file exists to refuse. File-wide denominator rule (measured 2026-11-08): every `n/28` ratio is the whole census — all 28 folders, the six lab fixtures included, since they ship the same content floor — and a row that measures a smaller population names it in-row. The fixtures' `SOURCE.md` label them `impeccable lab build`, which says what they are, not what they are excused from; no owner artifact exempts them from any row, so no row here exempts them silently. What governs is: (a) the floor every theme shares, each claim measured in the tree with its instrument named, and (b) the declaration that per-theme tokens own the design — in each theme's own `css/` (Colors, Typography, Shapes). The repo-root DESIGN.md is a SUPERSEDED pointer to `projects/portfolio/` ("Signalväg", a studio-rack world): a different surface's brand, not this salon's; nothing here inherits it.

## Colors

There is no shared palette and none is written here. Each theme owns its colour in a single `:root` token block in its own `css/` — 28/28 themes (instrument: `grep -rl ':root' <theme>/css/`, run 2026-11-08); 11 of 28 name the file `css/tokens.css` (00–08, 10, 27), the rest keep the block in their own `css/base.css`, `css/style.css`, `css/styles.css`, `css/mesh.css` or `css/chart.css`. The newest theme states the ownership rule for its own build: "nothing outside :root names a colour" (`27-salongens-rytm/css/tokens.css:2`). Placeholder state is canon: the shared `_assets/` art is generated gradient placeholders (`_assets/jane-portrait.ATTRIBUTION.md` — owner ruling R2 removed the original portrait, only its filename remains, and all themes point at the same generated file); `_assets` content is NOT salon photography and is not design material for any theme.

## Typography

Type pairings are per-theme, declared in each theme's own token block; no shared face exists. (Measured examples of the ownership pattern, not a shared system: `01-mork-guld/css/tokens.css:24-25`, `27-salongens-rytm/css/tokens.css:38-39`.) An external webfont is allowed only as a CSS link — "Google Fonts (CSS-länk)" (spec.md) — 23/28 themes reference fonts.googleapis (instrument: `grep -rl 'fonts.googleapis' [0-9]*/index.html [0-9]*/css/`, re-run 2026-11-08), while 27 ships local/system faces. The binding shared floor is offline legibility: stacks must fall back — "font fallback i font-stack" (spec.md), the page "fullt läsbar utan JS" (spec.md). What a conformance number means depends on the parse, so both parses are recorded (instruments re-run 2026-11-08 over each theme's `css/`): ANY-HIT — 16/28 themes contain at least one generic-terminated stack (regex `(font-family|--font[a-z-]*):[^;]*,[^;]*(serif|sans-serif|system-ui|ui-monospace|monospace)\s*[;]`; a theme counts here while other stacks of its own lack a fallback — "every font stack" was never what this regex measures). EVERY-HIT — over used stacks only (a `font-family:` declaration or a `--font*` token, outside `@font-face` — its `font-family` descriptors define a face name, not a stack — and pure numbers like `--font-normal: 400` are weight tokens), with `var()` resolved through each theme's own token block: 27/28 themes end every used stack on a generic family within that five-family vocabulary; 28/28 once `cursive` counts as the CSS generic family it is (the single remaining theme, `15-sagan-om-klippet`, terminates `"Patrick Hand","Segoe Print","Comic Sans MS",cursive`). Under the every-hit parse the offline fallback floor holds on all 28 folders as measured today — and stays a per-theme obligation: re-measure this row when a theme changes, never inherit the ratio.

## Do's and Don'ts

- Do treat `spec.md` as the only content canon and keep its Swedish strings exactly as written there — with ONE named exception: the portrait row (today the passage containing "Jane själv, spegelselfie i salongen" and a person-naming `alt` mandate for `../_assets/jane-portrait.jpg`). That passage is contradicted by the tracked `_assets/jane-portrait.ATTRIBUTION.md`: "Platshållarkonst genererad 2026-10-06 … Ingen fotokälla — ingen källbild har använts; originalporträttet togs bort ur produkten enligt ägarbeslut R2 (MC 10088)". Where the two disagree, ATTRIBUTION.md rules: no `alt` or caption may present `_assets` art as a photograph of a person — not even under the exact Swedish string spec.md still writes. Measured 2026-11-08: 25 of 28 `index.html` carry "Jane Cooper" in an `alt` attribute (misses: 00 — own `images/`; 15 and 18 — photo-free per spec.md's own named exception); de-staling the source string and the theme labels runs in parallel (MC 10088.30, MC 10088.31) — obeying this row must never re-import the stale string.
- Do put every per-theme design value in that theme's own `css/` token block — "inga delade mallar mellan teman" (spec.md).
- Do hold the placeholders visibly: the dash price, "(bekräftas snart)" and the "demo" labels stay until the real thing exists (`PRODUCT.md`, Brand Commitments, owner-ratified 2026-11-08).
- Do hold BOTH contrast bars: text 4.5:1 (3:1 large text) and non-text focus indicators ≥ 3:1 — different bars, different objects.
- Don't add a hex value, token name or font name to this file without a pointer into the tree that shows it exists: the file governs the floor; each theme's own `css/` owns the design.
- Don't present `_assets/` placeholder gradients as salon photography or brand material.
- Don't invent prices, reviews, opening hours or a booking system that does not exist (`PRODUCT.md`, Brand Commitments).
- Don't inherit the repo-root DESIGN.md — it is a SUPERSEDED pointer to portfolio's "Signalväg", a different surface's brand.
